MDraft v0.9.1 - Preview Toggle Fix

Problem:
- In v0.9.0 war die RenderIR-Vorschau intern vorhanden, aber nicht klar als aktivierbarer UI-Punkt erkennbar.
- Die Vorschau war außerdem initial aktiv, wodurch der Toggle semantisch unklar war.

Fix:
- Vorschau startet bewusst AUS.
- Ansicht -> RenderIR/HTML Live-Vorschau anzeigen
- Shortcut: Ctrl+P
- Menüpunkt ist explizit im nativen Win32-Menü und wird als checked/unchecked synchronisiert.
- Statuszeile meldet RenderIR/HTML Live-Vorschau aktiv/aus.

Datenfluss bleibt:
Markdown -> DisplayList/RenderIR -> GDI Preview
Markdown -> DisplayList/RenderIR -> SVG/HTML Export
