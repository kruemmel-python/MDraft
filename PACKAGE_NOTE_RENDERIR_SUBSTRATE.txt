MDraft v0.9.0 - RenderIR Substrate

Dieser Patch ersetzt die vorherige Live-Vorschau-Skizze durch einen gemeinsamen Render-Kern:

Markdown
  -> DisplayList / RenderIR
  -> Win32/GDI Preview
  -> SVG-in-HTML Export

Die Vorschau und der Export benutzen dieselben DrawCommands:
  Rect
  Line
  Text

Tests pruefen:
  - stabilen DisplayList-Hash
  - identische Command-Quelle fuer SVG/Preview
  - MathBox-Count
  - Mermaid Node/Edge-Count
  - deterministische Layout-Koordinaten durch DisplayList-Hash

Keine externen Libraries, kein WebView, kein CDN.
