MDraft v0.12.1 - GDI+ MSVC include substrate fix

Fix:
- render_gdi_win32.cpp now includes the COM/GUID headers required by gdiplus.h:
  guiddef.h
  unknwn.h
  objidl.h
  propidl.h

Why:
- The Win32 build uses WIN32_LEAN_AND_MEAN.
- With that ABI boundary active, windows.h does not pull every COM/GUID type
  GDI+ relies on.
- MSVC then reports missing IStream, PROPID and GUID declarations inside
  Windows SDK Gdiplus*.h while compiling render_gdi_win32.cpp.

The image RenderIR/GDI+ path remains enabled; this is not a feature rollback.
